# Workshop: ฝึกออกแบบฐานข้อมูล

[กลับสารบัญ DB-SHELF](../README.md)

รวมโจทย์ฝึกปฏิบัติสำหรับนำความรู้ Database Design มาใช้ตั้งแต่กำหนดกฎธุรกิจ ออกแบบตารางและ Transaction ไปจนถึงทดสอบและซ้อมกู้คืน แยกจากเลขบทเรียนหลัก

ทุก Workshop ใช้รูปแบบเดียวกัน: **เป้าหมาย → ขั้นฝึก 6 หัวข้อ → ตารางสิ่งที่ส่งมอบและเกณฑ์ตรวจ** เพื่อให้ลองออกแบบและอธิบายเหตุผลของตัวเองก่อนเทียบกับตัวอย่าง

## สารบัญ Workshop

| Workshop | ความยาก | สิ่งที่จะได้ฝึก | พื้นฐานที่แนะนำ |
|---|---|---|---|
| [ออกแบบระบบยืมหนังสือให้ครบวงจร](database-design-workshop.md) | กลาง–สูง | กฎธุรกิจ Grain, Keys, Constraints, Transaction, Query, Index, การทดสอบ และการกู้คืน | บท 1–19 ของ DB-SHELF |
| [Database Design และ Migration ด้วย Dataset จาก Kaggle](kaggle-design-and-migration.md) | กลาง–สูง | ออกแบบจาก Olist CSV, Grain/Constraints, Workflow ที่มี Data Cleansing และประวัติการแปลง Query/Index, Reconciliation และ Schema Migration | บท 1–4, 7, 9–12 และ 16–19 ของ DB-SHELF |

## ขั้นฝึกร่วมกันทั้งสอง Workshop

| ขั้น | หัวข้อ | สิ่งที่ต้องทำ |
|---:|---|---|
| 1 | กฎธุรกิจและข้อยกเว้น | ระบุความต้องการ แหล่งข้อมูล และสมมติฐานที่ต้องตรวจ |
| 2 | Grain และ Constraints | กำหนดความหมายของหนึ่งแถว คีย์ ความสัมพันธ์ และเงื่อนไขข้อมูล |
| 3 | Workflow | ออกแบบขั้นตอนหลัก Transaction และการรับมือคำขอหรืองานซ้ำ |
| 4 | Query หลักและ Index | เขียน Query ที่ต้องใช้ แล้วตรวจแผนก่อนเลือก Index |
| 5 | ทดสอบความถูกต้อง | กำหนดผลที่คาด ทดลองข้อมูลผิด และตรวจความครบตามโจทย์ |
| 6 | Migration และการกู้คืน | เปลี่ยน Schema อย่างมีขั้นตอน สำรอง และซ้อม Restore |

จบแต่ละ Workshop แล้วจัดทำชิ้นงานตามตารางสิ่งที่ส่งมอบในโจทย์ พร้อมเหตุผลที่เลือกและข้อจำกัดของผลงาน สามารถฝึกควบคู่กับบทเรียนแล้วกลับมาเติมส่วนที่ยังไม่เคยเรียนได้ ไม่ต้องรอหัวข้อขยายระบบบท 20–22

## เอกสารประกอบและชุดรัน SQL

Workshop Kaggle แยกคำสั่งและขั้นตอนรันไว้ใน [คู่มือ SQL](kaggle-sql/README.md) ตามลำดับ Raw Staging → Data Cleansing → Validation → Migration → Reconciliation พร้อมหลักฐานค่าก่อน/หลัง และ Expand–Backfill–Contract รวมถึงข้อมูลจำลองและชุดทดสอบ ส่วนหน้าโจทย์ Workshop เน้นลำดับฝึกและเกณฑ์ตรวจผลงาน

ลองออกแบบเองก่อนเปิดชุด SQL เพื่อเทียบแนวทาง หรือเริ่มรันด้วยข้อมูลจำลองเพื่อทำความเข้าใจ แล้วกลับมาอธิบายการออกแบบตามขั้นฝึกทั้ง 6 ข้อ
