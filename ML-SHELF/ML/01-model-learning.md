# 1. โมเดลเรียนรู้อะไร?

สมมติว่าเราต้องการทำนายราคาบ้านจากพื้นที่ เรามีตัวอย่างดังนี้:

| พื้นที่บ้าน | ราคาจริง |
|---|---|
| 50 ตารางเมตร | 2 ล้านบาท |
| 100 ตารางเมตร | 3 ล้านบาท |
| 150 ตารางเมตร | 4 ล้านบาท |

จากตัวอย่างนี้ พื้นที่เพิ่ม 50 ตารางเมตร ราคาก็เพิ่ม 1 ล้านบาท เราจึงลองใช้กฎนี้:

**ราคาที่ทำนาย = พื้นที่ × ราคาที่เพิ่มต่อตารางเมตร + ราคาเริ่มต้น**

เขียนเป็นสูตรได้ว่า:

$$
\hat{y}=wx+b
$$

อ่านสัญลักษณ์ทีละตัว:

| สัญลักษณ์ | อ่านว่า | ความหมายในตัวอย่าง |
|---|---|---|
| $x$ | เอ็กซ์ | พื้นที่บ้าน |
| $w$ | ดับเบิลยู | ราคาที่เพิ่มต่อพื้นที่ 1 ตารางเมตร |
| $b$ | บี | ราคาเริ่มต้นตามสมการ |
| $\hat{y}$ | วายแฮต | ราคาที่โมเดลทำนาย |

ในตัวอย่างนี้ ใช้หน่วยราคาเป็น **ล้านบาท** จะได้ $w=0.02$ และ $b=1$

ถ้าบ้านมีพื้นที่ 80 ตารางเมตร ให้แทน $x$ ด้วย 80:

$$
\hat{y}=0.02\times80+1=2.6
$$

จึงทำนายราคาเป็น **2.6 ล้านบาท**

การฝึกโมเดลคือการให้โปรแกรมค้นหาค่า $w$ และ $b$ ที่ทำให้ทำนายใกล้ราคาจริง ตัวอย่างนี้มีรูปแบบชัดเจนเพื่อให้เห็นวิธีคิด แต่ข้อมูลจริงมักไม่เรียงสวยแบบนี้ และอาจต้องใช้ข้อมูลอื่น เช่น ทำเลและอายุบ้าน

ในโค้ดจะเจอคำเหล่านี้:

- **Feature หรือ `X`:** ข้อมูลที่ใช้ทำนาย เช่น พื้นที่บ้าน
- **Target หรือ `y`:** คำตอบจริง เช่น ราคาบ้าน
- **`fit()`:** ให้โมเดลเรียนรู้จากตัวอย่าง
- **`predict()`:** ให้โมเดลที่ฝึกแล้วทำนาย

**ลองคิด:** บ้าน 100 ตารางเมตรตามสมการนี้ราคาเท่าไร? ลองแทนค่าก่อนอ่านต่อ คำตอบคือ 3 ล้านบาท

## ตัวอย่าง Python: ให้โมเดลเรียนรู้สมการ

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# X ต้องเป็นตาราง: แต่ละแถวคือบ้านหนึ่งหลัง แต่ละคอลัมน์คือ Feature
X = np.array([[50], [100], [150]])

# y คือราคาจริง หน่วยเป็นล้านบาท
y = np.array([2, 3, 4])

model = LinearRegression()
model.fit(X, y)  # ให้โมเดลเรียนรู้ค่า w และ b

new_house = np.array([[80]])
prediction = model.predict(new_house)

print("w =", model.coef_[0])       # ประมาณ 0.02
print("b =", model.intercept_)      # ประมาณ 1.0
print("ราคาที่ทำนาย =", prediction[0], "ล้านบาท")  # ประมาณ 2.6
```

ลองเปลี่ยน `80` เป็นพื้นที่อื่น แล้วสังเกตผลจาก `predict()`
