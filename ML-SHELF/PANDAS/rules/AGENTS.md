# กฎสำหรับเอกสาร pandas

กฎนี้ใช้กับเอกสารในโฟลเดอร์ ML-SHELF/PANDAS
อิง DataTypes.md เป็นตัวอย่างรูปแบบ และ Frontmatter.md เป็นคู่มือ metadata

## ภาษาและโครงสร้าง

- อธิบายเป็นภาษาไทย ใช้ชื่อ API และศัพท์ Python ตามจริง
- ใช้ชื่อไฟล์ภาษาอังกฤษแบบ PascalCase และนามสกุล .md
- ทุกไฟล์บทเรียนและสารบัญต้องมี YAML frontmatter ตาม Frontmatter.md
- ใช้หัวข้อระดับ 1 เพียงหนึ่งหัวข้อ และให้ตรงกับ title ใน frontmatter
- เรียงเนื้อหาเป็นบทนำ เตรียมข้อมูล หัวข้อเรียน แบบฝึกหัด และแหล่งอ้างอิง
- แยกหัวข้อหลักด้วยระดับ 2 และหัวข้อย่อยด้วยระดับ 3
- เว้นหนึ่งบรรทัดว่างระหว่างหัวข้อ ย่อหน้า รายการ และ code block
- ใช้ --- สำหรับเส้นคั่น ไม่ใช้ ___ หรือ ____
- ไฟล์ AGENTS.md เป็นกฎสำหรับผู้แก้ไข ไม่ต้องมี frontmatter หรือแบบฝึกหัด
- คู่มือรูปแบบ เช่น Frontmatter.md ไม่ต้องมีแบบฝึกหัดด้าน pandas

## ตัวอย่างโค้ด

- ใช้ fenced code block ระบุ python สำหรับโค้ด และ text สำหรับผลลัพธ์
- ใช้ bash สำหรับคำสั่งติดตั้ง
- โค้ด Python ระดับบนสุดต้องไม่เยื้อง ใช้ช่องว่าง 4 ตัวสำหรับบล็อกภายใน
- ใช้ import pandas as pd และ import ไลบรารีอื่นเฉพาะเมื่อเรียกใช้งาน
- แต่ละบทต้องมีข้อมูลเริ่มต้นที่สร้างได้เอง และรันตัวอย่างตามลำดับได้
- ใช้ชุดข้อมูลสินค้าเป็นหลักเพื่อเชื่อมเนื้อหาระหว่างบท
- ใช้ print() เมื่อสอนการแสดงผล เพื่อให้ตัวอย่างใช้ได้ในไฟล์ .py
- ระบุเมื่อคำสั่งต้องใช้ไฟล์จริง ไลบรารีเพิ่มเติม หรือข้อมูลจากบทก่อนหน้า
- อธิบายเมื่อคำสั่งสร้างผลลัพธ์ใหม่หรือแก้ข้อมูลเดิม
- ตรวจผลลัพธ์และข้อจำกัดที่มีผลต่อความเข้าใจ ไม่ใส่ผลที่ยังไม่ได้ตรวจเป็นข้อเท็จจริง

## แบบฝึกหัด

- ใช้หัวข้อ ## แบบฝึกหัด และระบุข้อมูลเริ่มต้นที่ต้องใช้
- ใช้เลขข้อจริง เช่น 1. ข้อความโจทย์ ไม่ใช้ Q1 หรือ Q2 เป็นป้ายกำกับ
- ใต้ทุกข้อมีบรรทัดว่างและ python code block สำหรับคำตอบ
- ข้อที่ยังไม่ได้ทำให้เว้น code block ว่าง ไม่เติมเฉลยอัตโนมัติ
- รักษาคำตอบที่ผู้ใช้เขียนแล้ว เมื่อปรับรูปแบบเอกสาร
- ถ้าผู้ใช้ขอตรวจ ให้รายงานข้อผิดและคำแก้ก่อน ไม่แก้คำตอบในไฟล์เอง
  เว้นแต่ผู้ใช้ขอให้แก้หรืออนุญาตไว้แล้ว
- แบบฝึกเพิ่มเติมสามารถใช้หัวข้อระดับ 3 และนับเลขข้อต่อเนื่อง

## ลิงก์และการตรวจงาน

- ลิงก์บทภายในด้วยชื่อไฟล์สัมพัทธ์ เช่น [Data Types](DataTypes.md)
- อ้างอิงเอกสาร pandas อย่างเป็นทางการในหัวข้อ ## แหล่งอ้างอิง
- เพิ่มบทเรียนใหม่ลงใน README.md พร้อมคำอธิบายและลำดับอ่าน
- ตรวจ frontmatter หัวข้อ code fences และลิงก์ภายในหลังแก้
- รันตัวอย่างที่เปลี่ยนเมื่อมี runtime และ dependency พร้อม
- ทดสอบตัวอย่างเขียนไฟล์ในพื้นที่ชั่วคราว เพื่อไม่เขียนทับข้อมูลผู้ใช้
- หากรันไม่ได้ ให้ระบุสิ่งที่ตรวจแล้วและข้อจำกัดจริงในรายงานผล
